# acceptjoel.com

My 2010 portfolio and application site for Parsons ("How to accept Joel in 5 easy steps"), restored from a backup and served as a static site on GitHub Pages.

The original ran on PHP with a MySQL database for the portfolio. This version is plain HTML, CSS and jQuery:

- The portfolio section was rebuilt by hand from the surviving images, since the database didn't survive. Project descriptions are blank.
- The contact form opens the visitor's email app instead of posting to a PHP mailer.
- Dead third-party embeds (Facebook Like box, Twitter feed, Clicky analytics) were removed.
